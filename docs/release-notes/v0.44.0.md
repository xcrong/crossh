# v0.44.0 — 会话常驻 daemon，多前端接入，CLI 开目录收敛到 open

> 2026-11-12 · 基于 v0.43.0 的 3 个提交

## ✨ Highlights

### 会话归属常驻 daemon

- 关窗口 / 退出 GUI 不再杀 shell：会话活在常驻进程里，重进回到原会话，长构建不再随窗口消失
- 一个会话可被多个前端同时接入：GUI + CLI 里 `crossh ls` 看到同一批会话；CLI 默认只读围观发送一次输入即接管
- 新 CLI 入口：`daemon`（status/start/stop）、`ls`、`run`（新会话跑命令取退出码）、`capture`（读会话回放环）
- 接入时重放旧设备查询（OSC 11 查底色、`CSI ? mode $ p`、DA）的应答直接在产生瞬间丢弃，不会灌回 shell 当输入执行

### 开目录收敛到显式 `open`

- `crossh <path>` 裸路径取消：开目录唯一入口是 `crossh open <path>`，裸写報錯并提示正确用法
- 与子命令同名的目录无需转义：`crossh open git` 直接能用原来的 `./` / `--` 转义作废

## 💅 Improvements

- 托盘图标换成品牌准星（薄荷绿 = daemon 可达灰 = 未运行），不再是程序生成的色块圆点
- 托盘"停止 Daemon"连带退出 GUI：daemon 没了 GUI 只剩空壳
- 认领会话后抖一下尺寸逼 shell 重画首帧不错位无需手动回车

## 🛠 Fixes

- 修复重放抑制的竞态：门控只放在消费侧时 `ReplayDone` 清旗跑在异步 drain 前面旧查询应答照样漏出去；现改在事件产生瞬间丢弃不进队列

## 🔧 Chores

- `link-preview-multi-platform` 的 C1 条件关闭（Linux `check` 补导入后三平台全绿）

## 📦 升级说明

- 首次启动自动拉起 daemon；**关窗口 / 退出 GUI 不再结束会话**（行为变更）
- **`crossh <path>` 改为 `crossh open <path>`**（行为变更，裸路径现在报错）
- `crossh daemon stop` 与托盘停止都会结束全部会话；托盘停止还会连带退出 GUI
- daemon 不写跨版本状态回滚即整体 revert提交
