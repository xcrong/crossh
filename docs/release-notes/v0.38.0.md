# v0.38.0 — 底部状态栏新增更新指示器

> 2026-10-06 · 基于 v0.37.1 的 1 个提交

## ✨ Highlights

### 更新不用再开设置页

- 底部状态栏最右侧新增更新指示器，把「检查 → 下载 → 重启安装」收进状态栏本身：未检查/已是最新/失败时点击即检查，仍是最新则弹出「已是最新版本」提示；发现新版本图标变为下载按钮，点击开始下载并在图标旁实时显示百分比；下载完成图标变为重启按钮，点击后交给 updater 子进程替换应用本体并退出（`src/features/workspace/view.rs`、`src/features/workspace/shell/update_indicator.rs`，`4bed839`）
- 检查与下载进行中按钮置灰，避免重复触发；失败时转为警示色，悬停 tooltip 给出具体原因
- 提示只在手动点击后弹出：启动检查与应用菜单的「检查更新…」不登记提示，不会每次启动都弹「已是最新」
- 指示器与设置页「更新」共用同一个更新控制器（外壳此前只被设置窗口订阅，现在也订阅更新状态以刷新状态栏），两处状态始终一致

## 📦 升级说明

- 无需手动迁移，直接内置更新即可。
- macOS（arm64/x86_64）、Linux（x86_64/aarch64）、Windows（x86_64）照常发布。
