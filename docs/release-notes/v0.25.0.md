# v0.25.0 — 独立笔记窗口 · Zed 同步

> 2026-08-28 · 基于 v0.24.1 的 3 个提交

## ✨ Highlights

### 独立笔记窗口 `crossh-note`

此前笔记受主窗口 `AppShell` 布局与焦点/IME 耦合限制，本版本彻底独立为第三个二进制，与 `crossh` / `crossh-git` 同包分发、共享同一份 `crossh-assets`（见 ADR 0016）。

- **入口**：主窗口底部状态栏 `FileText` 图标一键拉起；或 `crossh note` / `crossh-note` 命令行直启（同目录优先，缺失时回退 `PATH`）
- **窗口**：`900×600`（最小 `640×400`），原生 Zed `editor::Buffer::local` 纯文本编辑，完整支持撤销、IME、主题一致性，与 SSH/终端/SFTP 生命周期完全解耦
- **编辑 / 预览**：一键切换 Markdown 预览（`pulldown-cmark`，标题/粗体/斜体/行内代码/代码块/列表/引用/分割线），空内容显示“预览为空”
- **搜索**：`FTS5 (tokenize=unicode61)` 同时命中正文与标签，按 `pinned → updated_at → id` 排序；FTS 不可用时自动回退 `LIKE`（正确转义 `%/_/"`）
- **标签 / 置顶**：逗号分隔、自动 trim/去重；底部标签云一键过滤；`pinned` 笔记始终置顶
- **持久化**：`~/.config/crossh/note.db`（与 `settings.toml` 同目录），`WAL + user_version=1`，SQLite `notes` + `notes_fts` + 触发器自动同步；单条 8 KB / 标签 1 KB 上限（按 UTF-8 边界截断），损坏自动备份为 `note.db.corrupt.<ts>` 并重建

纯逻辑层 `crates/crossh-note` 零 `gpui` 依赖，符合 Logic/UI 分层红线。

## 💅 Improvements

- **布局修复**：标签输入框改为 `w_full` 固定高度、内容区独占 `flex_1`，根治窄窗口挤压；删除按钮上移至顶部 Header（`Danger` 样式，无选中时禁用）；预览区 `h_full + overflow_y_scroll` 独立滚动
- **交互**：搜索框支持 `↑/↓` 在列表中导航；复用 `shared/text_editing` 的垂直移动与鼠标命中逻辑，笔记与 SFTP 编辑行为一致（`IME composition` 移动时自动清理）
- **打包**：三二进制 `crossh` + `crossh-git` + `crossh-note` 共享 `crossh-assets/`，三平台一致

## 🛠 Fixes

- **存储健壮性**：损坏备份改用 `with_file_name` 避免路径错误；`ensure_schema` 有界重试（最多重建一次）；`tags`/`pinned` 迁移拆分为 `pragma_table_info` 独立探测；`all_tags()` 改为 `SELECT tags` 减少 IO
- **Markdown 预览**：`Options::all()` 精简为显式集合（`STRIKETHROUGH | TABLES | TASKLISTS | SMART_PUNCTUATION | HEADING_ATTRIBUTES`），避免未渲染的 footnotes/raw HTML 透传
- **窗口性能**：提取 `NOTE_*` 常量与 `line_starts`/`closest_byte_for_x` 辅助，修复 `line_start` 的 `O(n²)` 扫描；列表接入 `list_scroll + track_scroll` 保持滚动位；`reload_notes` 保留未保存草稿，避免搜索过滤时丢失输入
- **SFTP 编辑器**：移除 dead wrapper、直接 `import line_bounds`；移动时清理 IME 标记，修复中文输入残留

## 🔧 Chores

- **Zed 同步至 `f66ed399`（2026-08-26，领先 109 提交）**：全部 Zed git 依赖（`gpui` / `gpui_platform` / `terminal` / `settings` / `task` / `theme` / `editor` / `language` 等）由 `1b04e4c` 统一升级；`tree-sitter-language` 补丁同步至 `43623ec9`；适配 `TerminalBuilder::new` 破坏性变更（`task + completion_tx` → `TerminalMode::interactive()`，`path_hyperlink` 超时 `u64` → `Duration`）；`cargo check --workspace --all-targets` 与 `cargo test --workspace` 全绿

## 📦 升级说明

无需手动迁移。首次启动 `crossh-note` 自动创建 `note.db`；如需回退至 v0.24.1，直接替换二进制即可，`note.db` 独立于主配置。
