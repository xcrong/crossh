# v0.37.1 — 修复状态栏 git 状态不跟随焦点切换

> 2026-10-05 · 基于 v0.37.0 的 1 个提交

## 🛠 Fixes

- **底部状态栏的 git 段切到别的终端后要等十几秒才更新**。状态栏只渲染当前聚焦会话的 git 状态，后台 15 秒轮询也只轮询这一个会话；但切换焦点时没有任何补刷，于是切过去的瞬间显示的是该会话上次被聚焦时缓存的陈旧数据，必须等下一个轮询 tick 敲过来才追平。当前聚焦的那个之所以总是最新，正是因为它是唯一被轮询的对象。分屏把窗口拉得更大：非焦点的窗格可能已经几十秒没被刷新过（`src/features/workspace/shell/tabs.rs`，`33a3c7d`）
- 修复落在所有焦点切换路径的唯一收口上（切标签、分屏聚焦、焦点跟随鼠标、点击通知跳回、关闭标签后的焦点移交），因此无论怎么切换焦点，状态栏都会立刻跟上，无需等待轮询
- 开关分屏/标签时不会因此多 fork `git` 子进程：在途请求会被合并成一次后续检查，且 git 状态没变化时不触发重绘，沿用既有的去重规则

## 📦 升级说明

- 无需手动迁移，直接内置更新即可。
- macOS（arm64/x86_64）、Linux（x86_64/aarch64）、Windows（x86_64）照常发布。
