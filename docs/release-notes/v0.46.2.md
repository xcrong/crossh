# v0.46.2 — 安全加固与分栏线修复

> 2026-11-24 · 基于 v0.46.1 的 19 个提交

## 🛠 Fixes

- **拦截 `ext::` 远端 URL 命令注入**：`add_remote` 现在拒绝 `ext::`/`fd::` 前缀与 `--upload-pack` 等危险子串，之前 `ext::sh -c …` 可通过校验并在后续 `fetch` 时执行任意命令（`crates/crossh-core/src/git_remote.rs`）
- **Note 查找框 IME 可用**：查找框聚焦时输入法候选窗定位正确、组合串正常写入，不再因只认搜索框焦点而全返回空（`crates/crossh-note-view/src/window.rs`）
- **上下分栏双横线改为单线**：下方窗格不再重复画顶边框，分栏线本身就是分隔线；下方含焦点窗格时分栏线变 accent 色，焦点信号不丢（`src/features/workspace/view.rs`）
- **最小窗口 palette 不再溢出**：命令面板卡片改为视口相对尺寸（`max_w 90%`/`max_h 70%`），700×420 下不再被裁（`src/features/workspace/command_palette.rs`）
- **根焦点不再每帧抢占**：改为首次无焦点时认领一次，原生文件选择器/模态期间的 `Esc`/`Cmd+Q` 不再被吞（`src/features/workspace/shell/shell_render.rs`）
- **热路径偶发崩溃降为警告**：IME 竞态、窗口重建竞态、`tray icon` 解析、更新验签等 8 处 `unwrap/expect/panic!` 改为 `let-else + log` 降级（`compose_bar`/`app_menu`/`tray`/`command_palette`/`crossh-update`）
- **`crossh-git`/`crossh-updater` 补日志**：之前崩溃无日志可查，现在启动即落盘 `run.log` 并安装 panic hook（`src/bin/`）
- **终端超链接解析不再 panic**：路径大小写/Unicode 漂移时回退为无行列路径（`crates/terminal/src/paths.rs`）
- **Note 每帧重写主题**：`render` 内删除逐帧写全局主题，只在构造时同步一次（`crates/crossh-note-view/src/window.rs`）
- **Note 搜索超长查询不再整错**：搜索词截断 32 个，LIKE 失败改 warn 回退（与 FTS 对称），粘贴整篇文章不再返回错误（`crates/crossh-note/src/lib.rs`）

## 🔒 安全与隐私

- **`note.db` 收敛 0600/0700**：新建与老库打开时统一收敛权限，多用户机器不再明文可读（`crates/crossh-note/src/lib.rs`）
- **`/tmp` 日志防劫持**：日志目录收敛 0700，发现 symlink 时降级只打 stderr，不再跟随写受害文件（`crates/crossh-core/src/logging.rs`）

## 💅 Improvements

- **高频列表查询加速**：补 `idx_notes_list` 复合索引，笔记上万时列表/搜索不再全表扫描（`crates/crossh-note/src/lib.rs`）
- **图标缺失有回退**：未知 `IconName` 不再静默空白，开发期断言 + 线上 warn 并回退占位（`crates/crossh-ui/src/icons.rs`）
