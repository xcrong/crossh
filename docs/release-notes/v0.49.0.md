# v0.49.0 — 稳定性与交互修整

> 2026-11-27 · 基于 v0.48.0 的 13 个提交

## ✨ Highlights

### 一次全面扫描后的集中修整

本版本没有新特性，13 个提交全部来自 #Pig 流程扫出的 bug 与可观测性缺口。对日常使用影响最大的三件事：

- **终端不再无故杀进程**：字体 advance 测量失败、GPUI hitbox 缺失、不可见帧等过去会 panic 直接带走整个 GUI，现在改走 fallback / 早退
- **Linux 自更新不再「半更新」**：tar.gz / deb / rpm 用户改为整树替换，不再只换 AppImage 单文件而留下旧 daemon 与旧 resources
- **多窗口快捷键恢复**：根焦点从进程级静态变量改为每个窗口实例认领，第二个窗口的快捷键不再失效

## 💅 Improvements

- **静默失败终于可见**：Note 置顶失败给提示；session 12 处序列化失败写日志；`update_result` 落盘失败写日志，不再悄悄吞错
- **丢块有数可查**：实时转发的 `Lagged` 丢块由静默改为 `warn!`，日志能看到丢了多少块、是否可能需要重新 attach
- **compose 输入框能滚读长文本**：改为仅文本变化时滚到光标行，不再每帧强制滚到第二行
- **commit 多行编辑器补方向键**：`Up / Down` 不再冒泡去改文件列表的选中项
- **竖分屏可用性判定修正**：改用可用高度而非宽度，窄高窗不再被误禁用、矮宽窗不再重叠

## 🛠 Fixes

- **终端渲染去掉两处 `unwrap`**（`terminal_element_paint.rs`）：advance 测量失败改 fallback、GPUI hitbox 为 `None` 早退；此前任一条件都能让整个 GUI 退出。同批修掉该改动引入的 clippy 回归（`?` 替代 `let-else`）
- **关会话不再卡 tokio worker**（`ChildSession::Drop`）：把阻塞的 `wait / join` 挪到后台线程，不再占住运行时线程
- **Linux 自更新整树替换**（`crossh-update`）：目录式安装不再沿用单文件替换，避免 daemon / resources 停留在旧版导致协议握手失败、会话丢失
- **多窗口根焦点按实例认领**：去掉进程级静态变量，第二窗口快捷键恢复响应

## 🔧 Chores

- **CI 全量测试门禁**：补 `cargo test --workspace`；此前只跑少量定向测试，大部分 crate 测试零覆盖
- **三平台 clippy 对齐**：Linux 补 `force-warn`、Windows 补 clippy，并补无网络 feature 构建检查
- 清理 3 个既有 clippy 问题（死代码、嵌套 if、未用依赖）让门禁全绿；无 Zed 上游同步

## 📦 升级说明

- 无需手动迁移；会话、设置、笔记、SFTP 数据格式不变
- Linux tar.gz / deb / rpm 用户更新后请重启 daemon 与 GUI，确保 daemon、resources 一并换成新版，避免新旧协议不匹配丢失会话
- 如需回退，直接替换为 v0.48.0 二进制；Linux 目录安装回退时同样需整体还原安装目录，不要只替换单个可执行文件
