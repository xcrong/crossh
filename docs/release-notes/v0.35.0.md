# v0.35.0 — Git/Note Viewer 单实例复用与标签拖拽排序

> 2026-09-14 · 基于 v0.34.0 的 3 个提交

## ✨ Highlights

### Git/Note Viewer：单实例复用，不再重复启动

- 已有实例运行时，`crossh git <dir>` 转发到运行中的 Git Viewer（同目录聚焦，不同目录同窗口切换并刷新当前页）；`crossh note` 直接聚焦已有笔记窗口，无实例时正常启动（`src/bin/crossh-git.rs`，`src/bin/crossh-note.rs`，`4503c2a`）
- 复用通道与主窗口同构（回环 TCP + 每用户端口文件），三者端口文件分离（`instance.port` / `git.port` / `note.port`），实现收敛到 `crossh-core::single_instance` 供三个二进制共用（`crates/crossh-core/src/single_instance.rs`，`4503c2a`）
- 监听失败不阻断启动：退化为本地打开；转发被拒（目录在实例侧已失效等）直接报错退出，不再另起实例

### 标签页：拖拽排序

- 同组内把标签拖到目标标签上即排到它之前；打开/关闭/`cd` 触发的重建保留上一次相对顺序，不再打乱拖拽结果（`src/features/workspace/state.rs`，`src/features/workspace/tab_strip.rs`，`ee7eacd`）

### 命令面板：Git Viewer 与笔记入口

- 新增"为当前项目打开 Git Viewer"（聚焦会话的 cwd，无聚焦会话时空操作）与"打开笔记"两条命令，中英文关键词均可命中（`src/features/workspace/command_palette.rs`，`6116210`）

## 💅 Improvements

- 批量输入条更名为独立输入栏，tooltip 与文案同步（`locales/zh-CN.yml`，`6116210`）

## 🛠 Fixes

- Git Viewer 切目录时回到 Changes 页并刷新当前页：`compact_page` 在宽布局同样决定页面归属，不重置会命中 stale 分支漏刷（`src/features/git/window.rs`，`4503c2a`）

## 📦 升级说明

无需手动迁移。`crossh git` / `crossh note` 现在优先复用已运行实例；其他平台可直接内置更新。
