# v0.45.0 — 工作区布局移入常驻 daemon，协议升级到 v2

> 2026-11-18 · 基于 v0.44.2

## ⚠️ BREAKING

- 协议升到 v2：v1 客户端连新 daemon、v2 客户端连旧 daemon 都在握手阶段被拒绝，不会进入半可用状态
- 升级前先执行 `crossh daemon stop` 停掉旧 daemon；旧 daemon 中的会话随之结束
- 旧 settings 一次性导入工作区：`recent_local_dirs` 与 `pinned_local_tabs` 从 settings 移除，源文件旁保留 `settings.toml.pre-workspace` 快照

## ✨ Highlights

### 布局归 daemon

- 项目、tab、递归分屏树（行/列 + 比例）、焦点与 pane cwd 成为 daemon 的持久状态，落在 `<config-root>/daemon/workspace.json`；GUI 只消费 `WorkspaceSnapshot`
- GUI 退出或 daemon 重启后布局原样恢复；pane 身份稳定，会话在接入时按需物化，daemon 重启后按 pane 重建
- 分屏改为递归树，可任意层级嵌套；比例限制在 `0.05..=0.95`
- 每次修改的回执带新 revision；请求可带 `expected_revision` 做比较，回执分 `Applied` / `Unchanged` / `Conflict` / `Rejected`，并标明 `durable` 与 `storage_error`
- 持久化采用原子写入 + `.bak` 备份；损坏文件隔离为 `.corrupt-*`；工作区格式版本高于当前版本时拒绝启动，原因写入 `daemon/daemon.error`

### CLI 跟随工作区

- `crossh open <path>` 先在 daemon 中打开/激活项目，等修改回执成功后才聚焦或启动 GUI；路径无效、daemon 协议不兼容或回执超时以非零状态退出，不启动 GUI
- `crossh ls` 新增 `PROJECT TAB PANE` 列：`ID ROLE ALIVE PROGRAM PROJECT TAB PANE CWD`，临时会话显示 `-`
- `crossh daemon status` 只读，输出 `running (N sessions, port P)` + `workspace: N projects, N tabs, N panes`、`incompatible: found vN, expected vM; run crossh daemon stop`、`not running[ (stale port file)]` 三种状态
- `crossh daemon stop` 结束全部会话，保留工作区布局

## 💅 Improvements

- 配置根统一由 `crossh-core` 解析：`CROSSH_CONFIG_DIR` 直接作为根，settings 在 `<root>/settings.toml`，工作区在 `<root>/daemon/workspace.json`
- 旧 settings 在 daemon 首次启动时导入项目与固定标签，导入后旧字段不再被读取

## 📦 升级说明

- 升级前备份实际存在的 `settings.toml`，再执行 `crossh daemon stop` 停止旧 daemon
- 旧设置只导入一次；`settings.toml.pre-workspace` 是迁移前的快照，可据此手工恢复
- 回滚到 v0.44.x 后旧版本不读 `workspace.json`，且新版保存设置后 `recent_local_dirs` / `pinned_local_tabs` 已消失：最近目录与固定标签只能从备份恢复
