# v0.41.0 — 笔记：数据安全、自动保存与中英文界面

> 2026-11-07 · 基于 v0.40.1 的 2 个提交

## ✨ Highlights

### 笔记库不再丢数据

- 落库保存**原文**：此前会 trim 后再写，Markdown 代码块的首行缩进、刻意保留的首尾空行都被静默改写
- 删除改为软删：删完可在状态栏「撤销」，30 天后才真正清理；软删的笔记不再出现在列表与搜索结果里
- 损坏库不再表现为「笔记凭空消失」：只有确实不是数据库或已损坏时，才把旧库备份为 `note.db.corrupt.<纳秒时间戳>`（`-wal` / `-shm` 一起搬走）后重建，界面顶部提示备份路径，可手动关闭且关闭时把路径写进日志；`database is locked`、磁盘满等错误原样上抛，不会再触发洗库
- 打开库时设置 5 秒 `busy_timeout`，主应用与独立笔记进程同时访问不再直接报错
- schema 升到 v3，只在版本不足时重建全文索引，不再每次启动重跑一遍

### 笔记视图：停手 800ms 自动保存，删除可撤销

- 打字停顿 800ms 自动落库，保存就地更新列表行：不打断输入、不重排列表
- 删除是两段式（第一次标记、第二次真删），删后可在状态栏撤销；切换笔记后撤销入口自动收起
- 笔记在别处被删时，当前草稿自动改存成新笔记，而不是报一句「保存失败」就把内容留在编辑器里
- 编辑器右键菜单支持复制 / 剪切 / 粘贴 / 全选 / 撤销 / 重做，带平台快捷键提示（如 ⌘C、⇧⌘Z）
- 界面文案接入 rust-i18n：跟随主应用「语言」设置（English / 简体中文），独立的 note 进程启动时读取同一份 `settings.toml`

## 🛠 Fixes

- 判脏基准改为「载入时的正文快照」：此前在搜索框输入时，当前笔记会被过滤出列表，判脏退化成「非空即脏」——每敲一个字都白写一次库（推高修改时间、重跑全文索引，清空搜索后笔记跳序），极端情况下还会把被过滤的笔记复制成一条重复笔记
- 把一篇已有笔记整篇删空时说明「空内容无法保存」，不再只留一个永远亮着的「未保存」；撤销回原文或切到别的笔记后提示自动消失
- `crossh-note` 独立进程此前没有任何日志 sink：保存失败、删除失败、恢复失败的 9 处日志与全部 panic 信息都被静默丢弃。现在与主应用共用 `crossh_core::logging`（`/tmp/crossh/run.log`）并安装 panic hook
- 渲染热路径不再每帧把整篇正文物化成 `String`（1 MiB 上限的笔记此前每帧多次全量拷贝）

## 🔧 Chores

- 工程笔记：rust-i18n 在多 crate 下各归各的翻译表、以及 `i18n!` 编译期嵌入 YAML 导致增量构建沿用旧翻译表（已用 `cargo:rerun-if-changed` 修正）
- `env_logger` 依赖边从根包移到 `crossh-core`；`docs/architecture.md` 补上进程级 logging 的归属

## 📦 升级说明

- 无需手动迁移：首次启动自动升到 schema v3，并做一次全文索引重建
- 平台矩阵不变：macOS（arm64 / x86_64）、Linux（x86_64 / aarch64）、Windows（x86_64，aarch64 实验性）
