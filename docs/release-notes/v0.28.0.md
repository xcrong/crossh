# v0.28.0 — Command Palette 与悬浮临时终端

> 2026-09-01 · 基于 v0.27.0 的 8 个提交

## ✨ Highlights

### Command K 基础面板（`Cmd+K`）

全局 `Cmd+K / Ctrl+K` 唤起，`Esc` 或点击 `Scrim` 关闭，与 `Command Palette` 同款 `absolute inset_0 + scrim` 悬浮机制（`shell/shell_render.rs:106` / `command_palette.rs:422`）。

- **能力**：静态命令列表 + 模糊过滤 + 键盘导航（`↑/↓` 选中、`Enter` 执行），`PaletteCommandKind::ToggleScratchTerminal/OpenSettings/ToggleTimestamps` 等 MVP 集（`command_palette.rs:29`）
- **交互**：`ModalField` 复用 `IME/marked` 与 `ScrollHandle`，`focused` 自动聚焦、`on_key_down` 统一分发，`scrim` 阻止冒泡仅卡片内交互
- **入口**：`main.rs:132` 全局绑定 `cmd-k/ctrl-k`，状态栏与面板复用同一 `PaletteCommand` 定义

### 悬浮临时终端 Scratch（`Cmd+` / `Cmd+J`）重构为真悬浮

由底部 `flex` 抽屉改为与 `Command Palette` 同机制的居中悬浮 `Scrim` 卡片，不再挤压 `main(flex_1)`（`shell/shell_render.rs:51` 移除 `main_column` 内嵌，`root` 层 `absolute inset_0`）。

- **布局**：`scratch_bar.rs:16` `Scrim(pt 72) + 卡片` 居中，卡片默认 `80%` 视口（`w=viewport.w*0.8 / h=viewport.h*0.8`），`max_h = viewport.h-96` 窗口自适应，无固定 `MAX`（`scratch.rs:12` 移除 `SCRATCH_MAX_HEIGHT`），`min_h 200` 保底；初始 `scratch_height=0` 首次即 `80%`，拖拽后以 `Cell` 持久
- **拖拽**：复用 `SplitResizer(vertical)`（`scratch_bar.rs:102`），`max_h/min_h` 随视口动态，`bounds.origin.y → height = pointer_y - origin_y`，修复此前 `start_y` 每帧新建 + `header` 覆盖仅余 `4px` 命中区的“拖不动”（`582d1a7`）
- **目录**：`shell/scratch.rs:61` `scratch_initial_cwd` 固定 `dirs::home_dir()`，全局单例不再继承前景项目 `cwd`，避免项目污染；同 `PTY` 复用，`exit` 后自动清理
