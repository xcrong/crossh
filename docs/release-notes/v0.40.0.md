# v0.40.0 — OSC 7501 程序状态上屏：标签状态点、进度与悬停提示

> 2026-10-17 · 基于 v0.39.2 的 3 个提交

## ✨ Highlights

### 终端支持 OSC 7501 Program Status，标签页实时显示程序状态

- 支持 OSC 7501（Program Status Protocol）v0.4：终端里的程序（如 Agent、构建工具）上报 `working` / `blocked` / `done` / `error` 状态时，本地与 SSH 会话的标签页显示对应颜色的状态点，`working` 还会在标题后追加实时进度（如 ` 40%`）
- 悬停标签名可查看程序上报的状态消息（msg）；切回该标签页后 `done` / `error` 自动确认清除
- 实现为 PTY 读取路径上的观察式扫描（`crates/terminal/src/pty_tap.rs`）：不改动任何字节、零 unsafe，本地与 SSH 共用同一条路径；特性探测（`OSC 7501;?`）按规范应答，畸形输入按规范逐对跳过或整条丢弃，并带 4096 字节序列上限（`docs/terminal-compatibility.md`）
