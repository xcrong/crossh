# v0.27.0 — 终端 2×2 正交分栏

> 2026-09-01 · 基于 v0.26.0 的 22 个提交

## ✨ Highlights

### 终端 2×2 正交分栏（最大四格）

单 Tab 内支持左右与上下正交、最长 `TL/TR/BL/BR` 四格（`registry.rs:TerminalSplitState`），每 Tab 独立记忆。

- **布局**：`view.rs:render_terminal_split` 单列上下（`BL`）与双列（`TL/TR` 各自上下）按 `window.viewport_size().height` 响应式，`left_col/right_col` 加 `relative` 修正垂直 resizer 跨列逃逸，`render_split_column/render_single_column_vertical` 抽取消除 50 行镜像
- **独立拖拽**：`crossh-ui-component/split_resizer.rs` 新增 `SplitAxis::Vertical` + `drag_height(y-origin.y)`，`value/min_size/max_size` 通用化（`min_width/max_width` 保留为别名），`bottom(-4) h(8) cursor_row_resize` 横线；`view.rs` 左右列高度分 `split_heights / split_heights_right`，`left_top_height/right_top_height` 经 `split_clamped_size` 与 `terminal_split_top_height` 均分哨兵 `0`
- **交互**：顶部状态栏 `Columns2` 切左右、`Rows2` 切上下（`lucide 1.27.0 rows-2.svg`），上下按聚焦列决定 `BL vs BR`，`has_vertical` 仅看当前列，`can_add_vertical` 达 4 格后 `split_terminal_vertical_full`
- **状态一致**：`registry.rs:prepare_split_view_close` 对 `BR→Right` 晋升、`BL/BR` 单清时重置对应高度 `Cell→0`，`shell/split.rs:toggle_terminal_split` 快照右列原子关闭（单次确认覆盖 `BR+Right`），`prepare_terminal_split_view_close` 对属主关闭遍历 `secondary_views()` 逐一 `retire_split_pane`，`notifications.rs:jump_back_to_split_pane` 四路显式 `Left/Right/BottomLeft/BottomRight`，`focused_view` 跟随聚焦列
