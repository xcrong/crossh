## ✨ Highlights

### 链接点击分流

- `Cmd+点击` 用外部浏览器打开链接，`Shift+点击` 走内置预览（`crates/crossh-terminal`）
- 普通点击仍保持终端选区/跳转语义不变

### 临时终端抽屉

- 临时终端占满弹窗内容区，去掉多余留白（`src/features/workspace/scratch_bar.rs`）
- 悬浮时 `Cmd-D / Cmd-Shift-D` 不再穿透拆分背后工作区，`Cmd-Alt+方向键` 也不再抢焦点（`src/features/workspace/shell/split.rs`）
