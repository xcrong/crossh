# v0.46.1 — daemon 不再重复启动

> 2026-11-24 · 基于 v0.46.0 的 2 个提交

## 🛠 Fixes

- **daemon 不再重复启动**：重启 / 更新后不再累积孤儿 `crossh-daemon` 进程。之前握手失败（daemon 正忙、响应慢）会被误判为“已死”并删掉端口文件拉起新实例，老进程变成无文件可连的孤儿继续占 PTY、抢写 `workspace.json`，导致各种古怪问题。现在只有端口真正连不上才重建，握手失败直接报错不另起（`crates/crossh-session`）
- **关机不再误删接班人**：daemon 退出删端口文件前先比对 port + token，6 秒落盘窗口内已有新 daemon 认领时直接退出，避免新主人变孤儿

## 🔧 Chores

- 新增 gpui crates.io 迁移占位提案（内部文档，无行为变更）

## 📦 升级说明

- 无需手动迁移；工作区布局与会话保持不变
- 若之前已累积多个 `crossh-daemon`，升级后只会复用端口文件指向的那个，其余孤儿可手动 `kill`（先对照 `~/Library/Caches/crossh/daemon/daemon.port` 里的端口确认主人）
