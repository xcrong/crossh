# v0.45.3 — 修复自更新下载超时被误报为解码错误

> 2026-11-19 · 基于 v0.45.2 的 2 个提交

## 🛠 Fixes

- **更新下载不再受 30 秒总时限限制**：安装包下载改用独立的建连与读取空闲超时，慢速但持续的下载可以完成；此前 macOS 包在低于约 3.7 Mbps 的链路上会在中途超时
- **传输错误自动重试**：manifest 与安装包的加速源、GitHub 原站各重试两轮，瞬时中断后自动恢复；校验失败仍直接返回
- **错误原因可见**：更新失败信息展开底层 source 链，超时显示 `operation timed out`，不再只显示 `error decoding response body`
- **跟随系统代理**：reqwest 启用 `system-proxy`，从 Finder/Dock 启动的 GUI 也会使用 macOS 系统代理设置

## 📦 升级说明

- 0.45.2 内置的更新器仍会触发该问题，建议从 GitHub Release 手动下载 v0.45.3 覆盖安装一次；后续版本恢复自动更新
- 无需迁移工作区；旧 daemon 仍在运行时会自动停止并替换，工作区布局保留
