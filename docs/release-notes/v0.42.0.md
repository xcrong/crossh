# v0.42.0 — 终端链接就地预览：应用内临时网页卡片

> 2026-11-07 · 基于 v0.41.0 的 1 个提交

## ✨ Highlights

### 点链接不再跳走：应用内弹出一张网页卡片

- 终端里的链接（OSC 8 超链接、以及 `Cmd` / `Ctrl` + 点选的普通 URL）不再直接踢到系统浏览器，而是在当前窗口弹出悬浮卡片，终端与网页同时可见
- 整张卡片复用同一个原生视图：换链接只改导航，前进 / 后退历史与滚动位置都保留；右上角有后退、前进、在浏览器打开、关闭四个按钮
- 状态栏新增常驻入口「临时网页」，与「临时终端」并列：点它显示 / 隐藏上次看的网页并保留页面状态；本次会话还没打开过网页时，点它直接打开起始页 `cn.bing.com`
- `Esc` 关闭两条路径都通：焦点在应用里时由 GPUI 处理，点在网页里时由注入脚本经 IPC 转回
- 命令面板、右键菜单、重命名框等浮层打开时原生视图自动隐藏，关闭后立刻恢复，不会出现「弹窗被网页盖住」

### 卡片顶部的地址栏可以直接输入

- 粘贴或手输网址回车即导航；裸域名自动补 `https://`（`example.com`、`127.0.0.1:3000`、`localhost:8080` 都行）
- 输入框支持选区、光标移动、⌘A / ⌘C / ⌘V 与中文输入法组合，和命令面板、Git 远程输入框是同一套编辑语义
- 页面内点链接或发生重定向后，地址栏与「在浏览器打开」都跟随真实地址，而不是停在最初那一条
- `file:` / `mailto:` / `javascript:` 这类非 `http(s)` 协议不被卡片接管，与链接点击一致交回系统浏览器

## 💅 Improvements

- 终端 OSC 8 链接改走统一的视图层事件（`Event::Open`），与普通 URL 点击合并到同一个入口 `crossh_terminal_view::link_opener`：未安装 `LinkOpener` 时行为与之前完全一致，所以设置窗口、笔记等处的链接不受影响
- 新增 Lucide 1.27.0 官方图标 `arrow-right`、`external-link`（原始文件，未改动任何路径数据）

## 🔧 Chores

- 新增 `wry` 0.57 作为 **仅 macOS** 的依赖（`default-features = false`）：Linux / Windows 不引入 GTK / WebKitGTK，构建依赖与包体积不变
- 工程笔记新增《GPUI 内嵌原生 WebView：层级、坐标与焦点》，记录原生子视图恒在 GPUI 之上且不受裁剪、`set_bounds` 只吃逻辑坐标、点回 GPUI 一侧要回收 first responder、以及 GPUI 实体 lease 二次嵌套会 panic 这几处坑

## 📦 升级说明

- 平台差异：链接预览为 macOS 独有；Linux / Windows 点链接仍打开系统浏览器，无新增系统依赖
- 无需手动迁移配置；升级后状态栏会多出「临时网页」图标
