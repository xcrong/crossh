# v0.30.2 — Windows 安装程序与黑窗口修复

> 2026-09-03 · 基于 v0.30.1 的 4 个提交

## ✨ Highlights

### Windows 安装程序（setup.exe）

- 新增 Inno Setup 安装程序，与便携 zip 同内容（`crossh.exe / crossh-git.exe / crossh-note.exe / crossh-updater.exe + README + LICENSE`），同一暂存目录构建保证两者一致（`scripts/package-windows.ps1`，`scripts/crossh.iss`）
- 按用户安装到 `%LOCALAPPDATA%\Programs\crossh`，免 UAC；安装位置与版本无关，原地自更新继续有效；可选桌面图标与用户 PATH（`8379457`）

### Windows 黑窗口消除

- 启动不再附带常驻黑色控制台窗口：`crossh / crossh-git / crossh-note` 改为 `windows` 子系统；终端里 `--help / --version` 等 CLI 输出通过挂回父控制台保留（`6ec5eba`）
- 工作期间不再闪黑窗口：全部 `git` 调用收敛到 `git_command()` 唯一构造点（`CREATE_NO_WINDOW`）；自更新链路（updater 本体、`tasklist` 轮询、新版拉起）同步防闪（`6e30383`）

## 💅 Improvements

- Windows exe 嵌入应用图标（任务栏/资源管理器正常显示），打包脚本兼容多 Cargo Home（`$CARGO_HOME`、`USERPROFILE/.cargo`、scoop 等），`cargo metadata` 回退定位 Zed 资源（`ea0c338`）

## 🔧 Chores

- 新增工程笔记 `docs/engineering-notes/windows-console-flash.md`：控制台子系统闪窗根因与五条子进程拉起规则

## 📦 升级说明

无需手动迁移。Windows 用户可直接运行 `crossh-0.30.2-windows-x86_64-setup.exe` 全新安装，或继续用 zip 覆盖；自更新通道（`stable.json`）不变。下次 `git push origin v0.30.2` 将触发 `release.yml` 的 6 任务矩阵（`macOS aarch64/x86_64` + `Linux x86_64/aarch64` + `Windows x86_64`），`Windows aarch64` 仍为 `experimental continue_on_error`。
