# v0.30.1 — Linux 代理与打包修复，Bundle ID 统一

> 2026-09-02 · 基于 v0.30.0 的 8 个提交

## ✨ Highlights

### Linux AppImage 安装器与 Bundle ID 统一

- 全平台 `Bundle ID` 统一为 `me.xcrong.crossh`（`package.sh / package-linux.sh / main.rs / shell/mod.rs / crossh-git.rs / crossh-note.rs`，`aur/crossh-bin/PKGBUILD` 保留旧 `io.crossh.*` 兼容链接）
- `scripts/package-linux.sh` 产物改为 `me.xcrong.crossh.AppDir` / `me.xcrong.crossh.desktop` / `me.xcrong.crossh.png`，新增 `me.xcrong.crossh.AppImage` 同目录安装器 `scripts/install-linux.sh`（支持 `--user/--system`，`desktop/icon/Exec` 修复）与 `*-install.tar.gz`（`AppImage + install.sh`，`curl` 缓存 `runtime`，`ldconfig` 规避 `SIGPIPE`）

### GNOME 系统代理跟随

- Linux `LocalShellEnvironment::create_with_zdotdir` 新增 `gnome_proxy_env()`：`gsettings org.gnome.system.proxy mode==manual` 时读取 `http/https/ftp/socks host:port` 与 `ignore-hosts`，合成 `http_proxy/HTTP_PROXY https_proxy/HTTPS_PROXY ftp_proxy all_proxy/ALL_PROXY no_proxy/NO_PROXY`（`socks5://`），仅当父进程未显式设置时注入，修复桌面启动 `crossh` 子 shell 拿不到 `127.0.0.1:10808` 的问题（`crates/crossh-core/src/terminal/shell.rs`）

## 💅 Improvements

- `AppShell` 标签快捷键声明式化：`cmd/ctrl+tab` 与 `cmd/ctrl+1..9` 由 `handle_shell_key_down` 硬编码迁至 `shell::init` 的 22 条 `KeyBinding`（`Some("AppShell")`，复用 `context_stack` 冒泡），`tabs.rs` 新增 `switch_to_index / cycle_guarded`，`shell_render.rs` 补 11 个 `.on_action`，保留 `Escape` 模态拦截与 `should_block_tab_shortcuts`（`src/features/workspace/shell/*`，`src/main.rs`）
- 悬浮临时终端 `Scrim` 加 `.occlude()`（`BlockMouse`），`hit_test` 在 `scrim` 处 `break`，阻断滚轮穿透到底层终端（`src/features/workspace/scratch_bar.rs`，`7b4c5bf`）

## 🛠 Fixes

- `fix(package-linux):` `appimagetool` 的 `APPIMAGE_EXTRACT_AND_RUN=1` 场景下改为 `$(pwd)/dist` 绝对路径，避免 `dist/me.xcrong.crossh.AppDir` 相对路径在 `/tmp` 解压后 `no such file or directory`，并增加 `AppImage` 生成校验（`scripts/package-linux.sh`，`e36188b`）
- `fix(windows):` 本地 `cwd` 改用 `dunce::canonicalize` 去除 `\\?\` 扩展前缀，`PowerShell` 提示符不再渲染 `Provider` 裸路径（`85153b6`）

## 🔧 Chores

- 消融不必要抽象：删除单变体 `LaunchTarget` 与 `open_launch_target` 间接层，`main/on_reopen` 直调 `open_main_window`；合并 `crossh-theme`（117 行零依赖）至 `crossh-ui/palette.rs`；内联 `infrastructure/runtime+logging` 至 `app/bootstrap.rs`；`docs/architecture.md` 与 `scripts/check-architecture.sh` 同步（`691eb45`）
- 移除桩化与过期代码：删除 `crates/migrator-stub / settings-stub / settings_json-stub / theme_settings-stub` 四桩、`src/features/workspace/pane.rs / registry.rs`、`src/features/terminal/zed_view/terminal_element.rs` 冗余分支等 `815` 行，`Cargo.lock -48`（`bd22bb1`）

## 📦 升级说明

无需手动迁移。`~/.config/crossh/settings.toml` 与 `~/.local/share/crossh/note.db` 路径不变；Linux 用户如已安装旧 `io.crossh.*` 桌面项，`PKGBUILD` 与 `install-linux.sh` 已做兼容链接，新 `me.xcrong.crossh.desktop` 自动接管。下次 `git tag v0.30.1` 将触发 `release.yml` 的 6 任务矩阵（`macOS aarch64/x86_64` + `Linux x86_64/aarch64` + `Windows x86_64`），`Windows aarch64` 仍为 `experimental continue_on_error`。
