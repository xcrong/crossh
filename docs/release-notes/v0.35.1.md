# v0.35.1 — 修复 Windows 自更新失败

> 2026-09-17 · 基于 v0.35.0 的 2 个提交

## 🛠 Fixes

- **Windows 内置更新一直失败：`update archive contains an unsafe path: resources\crossh-assets\fonts\`**。发布 zip 由 Windows PowerShell 5.1 的 `Compress-Archive` 打出，它把 zip 条目分隔符写成 `\`，而规范要求 `/`；客户端解压时把反斜杠条目当路径穿越拒绝。包本身能下载、SHA-256 也校验通过，坏的是打包格式而不是更新渠道（`scripts/package-windows.ps1`，`b338654`）
- 解压改为先把反斜杠归一化为正斜杠再做安全校验，`..\` 之类的穿越路径仍会被拒绝；目录判定改用归一化名，否则反斜杠目录条目会被当成普通文件创建，同目录下后续条目全部写不进去（`crates/crossh-update/src/installer.rs`）
- 打包脚本改为手工写 ZipArchive 条目并统一用正斜杠，PS 5.1 与 PS 7 产出一致；补 UTF-8 BOM，避免 5.1 按 ANSI 解码中文注释导致脚本解析失败

## 💅 Improvements

- Windows zip 更新的载荷改为整体合并进安装目录：`crossh-git.exe`、`crossh-note.exe`、`crossh-updater.exe` 与 `resources/` 随主程序一起替换，不再只换 `crossh.exe`，各附属二进制与资源不再停在旧版本

## 📦 升级说明

- **Windows**：修复落在打包侧，坏的是 v0.35.0 及更早版本的发布 zip。旧版本内置的 updater 只拒绝反斜杠条目，能正常接受 v0.35.1 的 zip，因此可直接在设置页点更新；若仍失败，手动下载 zip 覆盖安装目录即可。
- 其他平台不受影响，可直接内置更新。
- 排查过程见 `docs/engineering-notes/windows-zip-backslash-separators.md`。
