# v0.48.0 — 全屏 TUI 重连自愈

> 2026-11-27 · 基于 v0.47.2 的 2 个提交

## ✨ Highlights

### 关窗口再回来，全屏程序不再乱屏

此前关掉 GUI 再重开，同尺寸回来时 `vim / htop / Claude Code` 这类全屏程序经常只剩碎片：首屏早被回放挤掉，重放全是没见过屏幕的差量，只能随便按个键逼它重画。本版本 daemon 记住是否在 `alt-screen`、环里还留没留首画，丢了就主动请程序重画一次。

- **所见即所得**：跑久的全屏程序关窗口重开，同尺寸直接恢复整屏，不用再 `Ctrl-L` / 乱按键自救
- **普通 shell 零打扰**：主屏提示符重连不抖不动，`p10k` 右提示首帧不错位
- **不处理信号的程序诚实降级**：极少数只在按键重画的 TUI 仍需一次按键，属协议极限，已在文档注明

## 💅 Improvements

- **回放按尺寸分段**：`resize` 即封段，重放按段带几何重建，跨尺寸重连不再串味
- **驱逐不对半截断**：`CSI/OSC/UTF-8` 中间不切，`33;C` 碎片与半个中文替换符不再出现
- **脱离期查询不 hang**：无客户端时 `DA / OSC 11` 由 daemon 按固定深色代答，`Claude Code` 类主题检查不再卡住

## 🛠 Fixes

- **双抖合并失效**：删除前端 `ReplayDone` 无条件双 `Resize`，改为 daemon 侧条件 nudge（`rows>1?rows-1:rows+1`，50ms 后恢复最新值，只动 PTY）
- **提示符误判**：重放是否在提示符改问内核前台进程组，避免刚重建的 `alt-screen` 被当垃圾清掉（`tty7#711` 同类）
- **旧端兼容**：未知帧学会跳过后再发 `Size=22` 新帧，新 daemon 配旧 GUI 不中断，新 GUI 配旧 daemon 单流退化不抖（`protocol.rs:180`）

## 🔧 Chores

- 新增能力标志 `reattach-nudge-v1`，四格退化表见 `design.md`
- 无 Zed 上游同步，本次仅含上述会话重连修复

## 📦 升级说明

- 无需手动迁移；会话、设置、笔记、SFTP 数据格式不变
- Windows 首版无自愈（无前台进程组信息，只回放），由 CI 断言；macOS/Linux 同尺寸重开即自愈
- 如需回退，直接替换为 v0.47.2 二进制即可；旧 daemon 会话随旧 daemon 结束，布局在 Shutdown 时落盘保留
