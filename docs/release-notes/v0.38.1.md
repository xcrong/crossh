# v0.38.1 — 侧栏底部固定打开项目入口，收起/展开不再乱序

> 2026-10-10 · 基于 v0.38.0 的 3 个提交

## 💅 Improvements

- **项目侧栏左下角多了固定的「打开本地项目…」按钮**。以前打开新项目要走 `⌘O`、命令面板或收起侧栏后的 `+` 菜单，现在展开的侧栏底部就有全宽次级按钮，点开即是系统目录选择器，与 `⌘O`、空状态页、rail 加号菜单走同一路径（`src/features/workspace/sidebar.rs`，`b9e8c5a`）

## 🛠 Fixes

- **开关项目侧栏时项目顺序不再跳变**。展开的侧栏按「有会话优先、其余按最近打开」排序，收起后的 rail 头像列却按路径字典序，两边对不上。现抽出统一的 `project_dir_sort_key`，rail 也按同一规则排序，同键时保持原有路径序（`src/features/workspace/sidebar.rs`，`b9e8c5a`）

## 🔧 Chores

- 编辑器删除 38 个无引用的 vendored widget，减约 28k 行，编译更快、包体积更小（`78aa7be`）
- 更新检查的 TLS 栈收进 `updates-network` 特性门，日常 `check` 跳过约 80 秒（`e7f1024`）

## 📦 升级说明

- 无需手动迁移，直接内置更新即可。
- macOS（arm64/x86_64）、Linux（x86_64/aarch64）、Windows（x86_64）照常发布。
