# v0.31.0 — 笔记打磨与终端右键/响铃

> 2026-09-03 · 基于 v0.30.2 的 7 个提交

## ✨ Highlights

### 笔记：去标签与中文搜索修复

- **存储层 tags 死列移除**：建表/FTS/触发器不再含 `tags` 列（该列从未透出到 UI，对用户无可见变化）；旧库打开时自动删列并重建 FTS 与触发器，无需手动迁移（`ee934b7`）
- **中文搜索可用**：此前 FTS5（`unicode61`）命中不了中文且直接返回空，本次 FTS 成功但结果为空时自动回退 `LIKE`，中文关键词能搜到正文，英文仍走 FTS 快速通道（`ee934b7`）

### 笔记：快捷键 / 脏保护 / 删除确认

- **快捷键**：新建、保存、删除、预览切换、列表上/下一条均有快捷键可用，不必全程点鼠标（`ee934b7`）
- **脏保护**：有未保存修改时切换笔记或刷新列表不再丢草稿，保存成功后才清除脏标记（`ee934b7`）
- **删除二次确认**：删除按钮第一次点击只标记目标并在状态栏明示“再按一次确认删除”，第二次才真删；按钮确认中变红，无弹窗打断（`ee934b7`）
- **错误提示**：存储打不开或查询/删除失败时标题区与列表区分别给出中文提示（查询失败显示旧数据、删除失败请重试），不再静默无反应（`ee934b7`）
- **搜索防抖与列表时间**：输入停止约 200ms 后才查库，连续输入不抖动；空列表区分“无笔记”与“搜索无匹配”，列表项带时间显示（`ee934b7`）

### 终端：WT 风格右键与响铃节流

- **右键改为复制/粘贴**：有非空选区时右键复制，无选区时右键粘贴，贴近 Windows Terminal 手感；鼠标接管模式（vim/less 等）仍直通 PTY，`Shift+右键`强制复制/粘贴；旧右键菜单及其分栏直发链路一并移除（`a136d6d`）
- **复制/粘贴成功弹 toast**：右键或快捷键复制粘贴成功后有轻提示，空剪贴板不再“点了没反应”（`7e905a7`）
- **响铃防刷屏**：同一终端可听铃声最多 2 秒一次，通知卡最多 10 秒一张，同终端新卡替换旧卡，`BEL` 刷屏不再淹没通知中心（`ef1a4e5`）
