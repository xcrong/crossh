# v0.31.1 — 修复 Linux AppImage 异机启动崩溃

> 2026-09-03 · 基于 v0.31.0 的 1 个提交

## 🛠 Fixes

- **Linux AppImage 在非构建机发行版上启动崩溃**：旧包把构建机（Ubuntu 22.04）的
  `libwayland/libxcb/libxkbcommon` 等显示栈库打进包内，盖住本机 Mesa 依赖的系统库，
  Vulkan/GL 后端全部初始化失败（`Failed to create surface for any enabled backend: {}`，
  空表），窗口建不起来（`b421339`）。
- **打包策略收窄**：AppImage 只携带字体栈（`fontconfig/freetype/harfbuzz`），显示栈与
  Mesa 直连库（`wayland/xkbcommon/xcb/X/ffi/glib/z/expat/lzma` 等）一律交由本机提供，
  详见 `docs/engineering-notes/appimage-bundled-libs-gpu.md`（`b421339`）。

## 📦 升级说明

- 已装坏版 v0.31.0 Linux AppImage 的用户请**手动下载 v0.31.1 重装**：坏版无法启动，
  内置更新够不着。其他平台与 tar.gz 用户不受影响，可直接内置更新。
