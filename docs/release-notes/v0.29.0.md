# v0.29.0 — 终端以 Crossh 为唯一真相

> 2026-09-02 · 基于 v0.28.0 的 3 个提交

## ✨ Highlights

### 终端 Fork 自持，不再依赖 Zed Settings

- 将 `zed/terminal` 完整 Fork 至 `crates/terminal`（5914 行），`crates/settings-stub` / `theme_settings-stub` 占位，`Cargo.toml` 移除 `settings`/`theme_settings` 直接依赖，`cargo tree --invert settings/wasmtime` 均 `did not match`
- 参数收敛至 `crossh-terminal` 单一真相：`TerminalSettings` 显式 `font_size 14/scroll 10000/line_height 1.618/minimum_contrast 45`，`from_crossh(px/scrollback)` 为唯一桥；`ThemeSettings` 链彻底移除

### 体积与启动

- 定向桩化 `migrator/settings_json` 的 `tree-sitter[wasm]`→`wasmtime/cranelift` 链，`Cargo.lock 972→925`，`settings_content 149M + wasmtime 633M/variant` 彻底消失
- 补 `theme::init(JustBase)`，`install_crossh_theme` 为唯一 `GlobalTheme` 写者，修复 `no state of type theme::GlobalTheme` 启动 panic

## 💅 Improvements

- 终端渲染以 Crossh 为准：`prepaint` 不再回退 `window.text_style`，`font_family "Lilex"` / `weight 400` / `px(14)` / `disable_ligatures` 显式兜底，`line_height 1.0→1.618` 与首帧 `TerminalBounds` 一致
- 资产单源化：`crates/crossh-ui::UiAssetSource` 在 `release` 始终回退 `ZedAssets`（编译期拷贝 `Lilex/IBM Plex Sans`），`list("fonts")` 永不为空，`X11` 亦可解析等宽
- `dev` 档降 `debug=1/split-debuginfo unpacked/opt-level z`，`target/debug/deps` 预估 `-30%`

## 🛠 Fixes

- 修复幽灵补全 `ls` 空格后 `zsh-autosuggest` 深灰沉底不可见：`minimum_contrast 0→45` 走 `APCA` 提亮，同步修正 `dim a*=0.7` 二次压暗
- 修复字体离散 `L a s t`：`window.text_style` 比例字体回退导致 `cell_width` 失配，改 `Lilex` 等宽并重算 `advance('m')`
- 修复 `cargo fmt --check` / `check-architecture.sh` 对 5925 行 Fork 的白名单与格式化

## 🔧 Chores

- Zed 同步至 `f66ed399`（2026-08，领先约 200 提交），`assets` 仍以编译期拷贝形式复用
- `scripts/check-architecture.sh` 增加 `crates/terminal/src/terminal.rs` 白名单

## 📦 升级说明

无需手动迁移，`~/.config/crossh/settings.toml` 的 `terminal_font_size/terminal_scrollback` 自动经 `from_crossh` 生效；`~/.config/zed/settings.json` 的尾逗号/注释保持兼容（`serde_json_lenient`）。
