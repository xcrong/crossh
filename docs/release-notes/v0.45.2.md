# v0.45.2 — 修复分屏快捷键、shell 退出与 Windows 一次性命令

> 2026-11-19 · 基于 v0.45.1 的 10 个提交

## 🛠 Fixes

- **分屏快捷键继续拆分**：`Cmd+D` 左右分屏后再按 `Shift+Cmd+D`，会在当前 pane 上继续拆出上下分屏，形成三个 pane 的嵌套布局，不再把已有的左右分屏收掉；命令面板的“左右分栏 / 上下分栏”同步使用该行为
- **shell 退出关闭对应 pane**：在分屏的一侧输入 `exit`，该 pane 会从界面移除，兄弟 pane 占据原空间；tab 的最后一个 pane 退出后 tab 被删除。重复或迟到的退出通知不会再次改动布局
- **Windows 一次性命令不再挂起**：`crossh run -- cmd /C ...` 在 ConPTY 下由 daemon 代答启动光标查询；attach 在回放前或回放期间退出的会话也能收到退出通知与退出码
- **Windows 链接预览恢复**：悬浮预览不再被 macOS 门控挡住，Windows 上可正常显示；移除未使用的 Markdown 解析依赖
- **工作区写盘失败立即回执**：结构性修改写盘失败时立刻返回 `durable=false` 与 `storage_error`，不再等待写入超时；失败期间后续写入继续退避重试

## 🔧 Chores

- CI 增加 macOS 格式检查、架构检查、Clippy、应用测试与终端回放检查，以及 Linux/Windows 的 session 测试
- PTY 回放环按字节裁剪，回放长度稳定为 512 KiB
- 迁移测试改用跨平台临时目录构造，修复 Windows 断言失败

## 📦 升级说明

- 从 v0.45.1 直接更新并重启 GUI 即可，无需手动迁移
- 如果旧 daemon 仍在运行，GUI 会自动停止并替换它；旧 daemon 中的会话结束，工作区布局保留
