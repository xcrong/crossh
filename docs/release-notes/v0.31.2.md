# v0.31.2 — Linux AppImage 改用 linuxdeploy 打包

> 2026-09-03 · 基于 v0.31.1 的 2 个提交

## 🛠 Fixes

- **v0.31.0 的 AppImage 在非构建机发行版上启动崩溃**：包内旧构建机的
  `libwayland/libxcb` 盖住本机 Mesa 依赖，Vulkan/GL 后端全部初始化失败
  （`Failed to create surface for any enabled backend: {}`）。
- **v0.31.1 修出新问题**：打包了构建机的 `libc.so.6`，本机新库报
  `GLIBC_2.38 not found` 起不来。
- **根治：打包改用上游 linuxdeploy**：手写依赖收集两次翻车，此后规则不再手写；
  显示栈（`wayland/xkbcommon/xcb`）显式排除走本机，`libc/GL/EGL/Vulkan` 等用其
  内置规则排除；生成 AppRun 走 rpath，不再向子进程泄漏 `LD_LIBRARY_PATH`。
  详见 `docs/engineering-notes/appimage-bundled-libs-gpu.md`。

## 📦 升级说明

- v0.31.0 / v0.31.1 的 Linux AppImage 用户请**手动下载 v0.31.2 重装**：
  坏版无法启动，内置更新够不着。其他平台不受影响。
