# v0.25.1 — 修复笔记窗口打包缺失

> 2026-08-28 · 基于 v0.25.0 的 2 个提交

## 🛠 Fixes

### 打包脚本补全 `crossh-note`

- v0.25.0 新增的独立笔记窗口 `crossh-note`（见 ADR 0016）在三平台打包脚本中被遗漏，导致 `dist/crossh.app/Contents/MacOS/crossh-note` / Linux `tar.gz`+`AppImage` / Windows `zip` 均未包含该二进制，`crossh note` 命令与主窗口底部状态栏 `FileText` 入口回退 `PATH` 查找失败。本版本在 `scripts/package.sh:36,45,89` / `scripts/package-linux.sh:26,33,41,57` / `scripts/package-windows.ps1:26,65` 中补齐 `cargo build --bin crossh-note`、产物拷贝与 macOS `codesign --identifier io.crossh.app.note`（对应 `src/bin/crossh-note.rs:67` 的 `AppIdentity`），`scripts/mac_local_install.sh` 透传 `package.sh` 同步修复，`release.yml` 三平台矩阵无需改动自动生效。

## 🔧 Chores

- 新增 `release` 发布流程 skill，手写发布日志为强制要求，避免直接粘贴 `git log` 作为 Release Notes。

## 📦 升级说明

无需手动迁移。已安装 v0.25.0 的用户覆盖安装 v0.25.1 即可获得 `crossh-note`；`note.db`（`~/.config/crossh/note.db`，`WAL + user_version=1`）独立于主配置，回退到 v0.25.0 仍可使用；三平台产物校验与 `stable.json` Ed25519 签名流程不变。
