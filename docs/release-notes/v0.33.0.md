# v0.33.0 — CLI 单实例复用打开项目

> 2026-09-04 · 基于 v0.32.0 的 10 个提交

## ✨ Highlights

### CLI：`crossh [PATH]` 复用运行中实例打开项目

- 已有实例运行时，`crossh ~/Code/foo` / `crossh .` 直接在该实例中打开项目并前台激活，无实例时正常启动；裸 `crossh` 仅聚焦已有实例（`src/app/single_instance.rs`，`src/app/cli.rs`，`81f714b`）
- 单实例通道为回环 TCP + 每用户端口文件转发，前台激活收敛到 `app_menu::activate_project`（含零窗口时重建）
- 与子命令同名的目录（`git`/`note`/`help`）用 `./` 或 `--` 转义，help 文本与 README 同步更新
