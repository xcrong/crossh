# v0.32.0 — Git 远端管理与历史文件 Diff、命令面板补齐

> 2026-09-04 · 基于 v0.31.2 的 9 个提交

## ✨ Highlights

### Git：远端管理标签页

- Git 窗口新增 Remotes 标签：远端列表、单个/全部抓取、内联添加表单、删除二次确认（`src/features/git/remote*.rs`，`f73a4d3`）
- 核心层新增 `git_remote`（list/fetch/add/remove + 校验），输入层 IME 路由收敛为 focused_text_state（`crates/crossh-core/src/git_remote.rs`，`f73a4d3`）
- UI 层新增共享 `labeled_field` 表单行组件，供添加表单复用（`f73a4d3`）

### Git：历史提交文件级 Diff

- 历史详情改为三栏：commit 信息横跨，左文件列右 diff 列，窄屏保持纵向（`src/features/git/history_render.rs`，`2971c0d`）
- 按文件取 unified diff（`-m --first-parent` 覆盖合并提交），文件列表按内容定高（封顶 5 行），默认选中首个文件自动加载（`crates/crossh-core/src/git_history.rs`，`2971c0d`）
- diff 列表加常显横向滚动条（6px 主题强调色），Changes 页同步（`2971c0d`）

### 命令面板：分栏/编辑器/退出/最大化

- 新增左右分栏、上下分栏、在编辑器中打开当前项目、最大化窗口、退出应用等命令，中英文案齐备（`src/features/workspace/command_palette.rs`，`ca35d73`）
- 命令新增英文关键词匹配（如 `zoom` 配 `maximize`，分栏配 `left/right/up/down`），过滤时与标签/id 同权（`ca35d73`）

### Linux：原生发行版包

- 安装包由 `-install.tar.gz` 改为 `<AppImage>.tar.gz`（AppImage + install.sh），`dpkg-deb`/`rpmbuild` 组装 `.deb`/`.rpm`，FHS 布局（`/usr/bin` + `/usr/share/crossh`）（`scripts/package-linux.sh`，`943bb42`）
- `crossh-assets` 资源发现回退 `/usr/local/share` 与 `/usr/share` 系统路径并补单测（`943bb42`）

## 💅 Improvements

- `crossh-git` 跟随主应用语言设置，中英文切换一致（`crates/crossh-core/src/locale.rs`，`9e22a68`）
- 关闭分栏 Tab 时关闭整个 Tab，不再晋升右窗格，符合分栏心智（`src/features/workspace/shell/tabs.rs`，`8f88ef3`）

## 🛠 Fixes

- 命令面板输入截断冒泡，同一按键不再被两处监听各插入一次（`new` 变 `nneeww`）（`src/features/workspace/command_palette.rs`，`e68f3c5`）

## 🔧 Chores

- 新增 `crossh-ui-base` 行为基座（button/layout/list_state/panel/positioner/split/text_selection/text_state/avatar_text/toast_placement/toggle 共 11 个纯逻辑模块），组件层改为委托到该缝线；`check-architecture.sh` 增补基座规则（`08baeb0`，`5f71af5`）
- 上述 UI 拆分对用户无可见变化，仅为后续复用打基础

## 📦 升级说明

无需手动迁移。Linux 用户注意包名变化：旧 `-install.tar.gz` 改为 `*.AppImage.tar.gz`（含一键安装脚本），另新增 `.deb`/`.rpm` 可直接系统安装；其他平台可直接内置更新。
