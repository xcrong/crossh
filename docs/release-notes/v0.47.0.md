# v0.47.0 — 更新原子化与窗口稳定性

> 2026-11-25 · 基于 v0.46.2 的 22 个提交

## ✨ Highlights

### 更新载荷整树原子替换

- 更新安装改为整树原子替换，失败不留半更新，断电/中断后下次仍可完整重试（`crates/crossh-update/src/installer.rs`）
- `tar.gz` 全量同样走整树替换，旧 daemon 不再残留导致新旧混跑（`crates/crossh-update/src/installer.rs`）
- 新增单文件上限与磁盘空间预检，包损坏或空间不足时提前报错，不再把磁盘打满（`crates/crossh-update/src/installer.rs`）

### 窗口打开失败不再崩溃

- `open_window` 失败改为记日志优雅返回，git/笔记窗口创建失败时主窗口继续可用（`crates/crossh-git-view/src/window.rs`，`crates/crossh-note-view/src/window.rs`）

### GPUI 同步至 2664a0a

- 跟随上游到 `2664a0a`，编辑器滚动条/文本选区/终端元素按新 API 适配，用户侧无感知（`crates/crossh-editor`，`crates/crossh-terminal-view`）

## 💅 Improvements

- **链接预览更干净**：顶栏去掉 tooltip，macOS 原生悬浮不再盖住预览；点 X 显式释放 webview，点外部仅隐藏（`src/features/workspace/shell/link_preview.rs`）
- **侧栏不再进空态**：收起侧栏与最近项目改走打开语义，无项目时不再停在空白页（`src/features/workspace/sidebar.rs`）
- **退出不留临时终端**：退出时显式关闭 scratch 临时终端，后台不再遗留空跑进程（`src/features/workspace/shell/scratch.rs`）
- **设置损坏只丢坏字段**：终端工作区设置改为逐字段回退，一个坏值不再清空整份配置（`src/features/settings/persistence.rs`）
- **主配置坏了有备份兜底**：主配置解析失败时回退读 `.bak` 并补权限日志（`src/features/settings/persistence.rs`）
- **配置根必须绝对路径**：相对路径直接报错并规范化，避免工作目录一变就写错地方（`crates/crossh-core/src/config/mod.rs`）

## 🛠 Fixes

- **输入法光标越界不再 panic**：光标选区钳到字符边界，CJK 组字/越界拖选只做修正（`src/features/workspace/compose_bar.rs`）
- **非 UTF-8 路径不再合流**：git 路径改字节透传，重命名两边对不齐时不再误判（`crates/crossh-core/src/git/`）
- **版本号解析失败不崩**：更新状态回 `Failed` 并可重试，坏的 manifest 不再卡死更新页（`src/features/updates/mod.rs`）
- **同秒建会话不再覆盖**：隔离名加入 pid+纳秒，临时目录加随机后缀（`crates/crossh-session/src/workspace_store.rs`）
- **托盘与权限看得见了**：托盘快照失败加日志、`stop` 失败记 warn，落盘同步失败与权限收敛都有据可查（`src/infrastructure/tray.rs`）

## 🔧 Chores

- session 测试改 `file_serial` 跨进程串行，`LANG` 移到 runtime 之前，CI 偶发抢端口显著减少（`crates/crossh-session/tests/`）
- 编辑器启动命令显性化信任边界：只认受信配置与系统 PATH，不再静默执行可疑项并记审计日志（`crates/crossh-core/src/editor_launcher.rs`）
- 纵深小项收敛：note 空值约束、compose 空提交守卫等 4 处补齐（`crates/crossh-note`，`crates/crossh-update`）

## 📦 升级说明

- 无需手动迁移；会话、设置、笔记数据格式不变
- 更新链路为原子替换，建议更新后重启一次以确认新 daemon 生效
