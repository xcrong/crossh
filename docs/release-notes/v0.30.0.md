# v0.30.0 — 笔记编辑器换核与主题拉取

> 2026-09-01 · 基于 v0.29.0 的 2 个提交

## ✨ Highlights

### 笔记编辑器由自绘换为 crossh-editor 引擎

- 将 `longbridge/gpui-component` 的 `crates/base` 全量 vendor 至 `crates/crossh-editor`（`b2b7e41`，`74k` 行，`Apache-2.0`），保留 `Rope`+`UndoManager`+`DisplayMap`+`TextElement` 纯引擎，`crates/crossh-editor/README.md` 记录来源与同步指引
- `NoteWindow` 由 `TextEditingState`（`String`+`closest_byte_for_x` 手写 `EntityInputHandler`）重写为 `InputState`/`TextareaState` 薄封装（`crates/crossh-editor/src/input/base/state.rs:4973`），`soft_wrap`、`history`、`IME/UTF16`、`grapheme` 移动与 `selection` 交由 `TextElement` 统一处理，`src/features/note/window.rs 1605→832` 行

### 主题与右键菜单随动

- 主题改为**拉**模式：`sync_editor_theme` 每帧把 `crossh_theme` 写入 `crossh_editor::Theme::global_mut` 的 `tokens.colors`（`foreground/muted_foreground/background/surface/border/accent/selection`），`InputEditorStyle::resolved` 自动拉取；根 `div.text_color(theme::text())` 使 `window.text_style().color` 正，修复暗字暗底
- 右键菜单：`InputState/TextareaState.on_context_menu` 透传 `InputContextMenuCapabilities`，`NoteWindow.open_context_menu` 按 `has_selection/is_editable` 构 `复制/剪切/粘贴/全选/撤销/重做`（`⌘C/X/V/A/Z`），`render_context_menu` 覆盖层经 `window.dispatch_action(Copy/Cut/...)` 派发

## 💅 Improvements

- `crossh-note` 独立进程瘦身：移除 `src/shared/text_editing.rs` 的 `#[path]` 复用，`src/bin/crossh-note.rs` 仅复用 `note/*`，`crates/crossh-note` 保持 `SQLite+FTS5` 纯存储
- `crates/crossh-editor` 内 `benches`/`tests` 清理、`#![allow(clippy::all)]` 与 `Cargo.toml` `lints.clippy = allow`，避免 `cargo clippy --workspace --all-targets -D warnings` 在 vendor 上误报

## 🛠 Fixes

- 修复 `crossh-note` 文字颜色过暗：`TextElement` 主文字 `window.text_style().color` 未继承 `theme::text()`，占位 `muted_foreground` 未经 `Theme` 拉取
- 修复选中后右键无菜单：`enable_context_menu=true` 但 `context_menu_handler=None`，`pending_context_menu` 永远不弹，现补 `on_context_menu` 句柄
- 修复笔记切换时 `display_map` 与 `Rope` 不一致导致的 `debug_assert_eq!(line_item.len(), line_text.len())`（`set_value_simple` 补 `on_text_changed`）
- 修复 `cargo clippy` 在 `crates/crossh-editor` 的 292 例 `unused_unit/redundant_static_lifetimes/new_without_default` 误报

## 🔧 Chores

- `fix(ci): 修复 Linux/Windows 发布构建失败`：`release.yml` 补 `libxkbcommon-x11-dev`，`crates/terminal/Cargo.toml` 补 `windows = { features = ["Win32_Foundation","Win32_System_Threading","Win32_Storage_FileSystem"] }`（回归 `5c58604`）
- `scripts/check-architecture.sh` 增加 `crates/crossh-editor/*` 白名单，保持 vendor 差异可比
- `THIRD_PARTY_NOTICES.md` 追加 `crossh-editor input engine` 条目

## 📦 升级说明

无需手动迁移；`crossh-note` 的 `8KB` 截断与 `NoteStore` 保持兼容，`~/.config/crossh/settings.toml` 不变。下次 `git tag v0.30.0` 将触发 `release.yml` 的 6 任务矩阵（`macOS aarch64/x86_64` + `Linux x86_64/aarch64` + `Windows x86_64`），`Windows aarch64` 仍为 `experimental continue_on_error`。
