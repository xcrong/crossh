> 2026-11-06 · 基于 v0.40.0 的 2 个提交

## 🛠 Fixes

### Git 查看器：新增 / 未跟踪文件看不到内容

- 2 秒轮询此前用变更条目的元数据（状态、暂存态、增删行数）判断要不要重读 diff。未跟踪文件不在 `git diff --numstat` 的输出里，两个行数恒为 `+0 −0`；等行数改写统计同样不变——元数据看不出差别，diff 就永远停在首次加载的那一帧。
- 现在每次扫描成功后一律重读当前选中条目，用 `FileDiff` 内容本身比较，内容相同则不重绘；另加在途去重（`diff_in_flight`），慢盘上的慢 diff 不会被下一轮扫描反复挤掉，「加载中」不再闪。
- 验收路径：新建空文件 → 在查看器里选中它 → 写入内容并保存 → 2 秒内 diff 出现内容。
