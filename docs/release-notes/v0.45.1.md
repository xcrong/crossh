# v0.45.1 — 更新后自动替换不兼容的 daemon，收起侧栏恢复只列活跃项目

> 2026-11-18 · 基于 v0.45.0 的 2 个提交

## 🛠 Fixes

- 更新后旧 daemon 卡住：GUI 握手发现 daemon 协议不兼容时，会按对端报告的版本完成握手、发送 `Shutdown`，等端口释放后自动拉起当前版本的 daemon，不再需要进进程管理器强杀。旧 daemon 中的会话随之结束，工作区布局保存在 `workspace.json`，新 daemon 启动后照常恢复
  - 只在探测到“存活但不兼容”时停止旧实例；并发客户端已拉起新 daemon 时不会误杀
  - `crossh daemon stop` 同样按对端报告的版本握手，后续协议升级仍能停止
- 收起侧栏多显示项目：collapsed rail 只列出存在 `Live` / `Starting` 会话的项目，恢复旧版行为；没有会话的项目只在展开侧栏出现

## 📦 升级说明

- 从 v0.45.0 直接更新并重启 GUI 即可：首次连接时旧 daemon 会被自动停止并替换，旧 daemon 中的会话结束，工作区布局与历史保留
- 也可以在更新前手动执行 `crossh daemon stop`，效果相同
