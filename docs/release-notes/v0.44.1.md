# v0.44.1 — 安装包带上 crossh-daemon

> 2026-11-15 · 基于 v0.44.0 的 1 个提交

## 🛠 Fixes

- 安装包缺失 `crossh-daemon`：v0.44.0 打出的包（dmg/zip、tar.gz、AppImage、deb、rpm、setup.exe）里没有 daemon，安装后 GUI 启动即报 `cannot reach daemon: crossh-daemon not found next to ...`，终端页不可用
- macOS / Linux / Windows 三处打包脚本补上 daemon 的构建、拷贝与收录：macOS 进 `Contents/MacOS` 并单独签名；Linux 进 tarball / AppDir / deb，linuxdeploy 加 `-e` 收录依赖，rpm `%files` 同步；Windows 进 stage/zip（`crossh.iss` 通配符自动带入 setup.exe）
- 自更新链路同步覆盖：mac 整包替换、Windows 顶层载荷合并、Linux AppImage 整体替换，老版本自更新上来即恢复正常
- 仅注释：自更新器顶层结构注释补上 `crossh-daemon.exe`

## 📦 升级说明

- 无需手动迁移；从 v0.44.0 自更新到本版即可
- 不受影响：`cargo run` 本地开发（`target/debug` 里 daemon 一直都在）
- 急用可手动补：`cp target/release/crossh-daemon /Applications/crossh.app/Contents/MacOS/` 后重签，或重跑 `scripts/mac_local_install.sh`
