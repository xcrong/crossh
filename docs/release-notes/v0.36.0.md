# v0.36.0 — Git 分支一键复制 + idle 资源优化

> 2026-09-23 · 基于 v0.35.1 的 9 个提交

## ✨ Highlights

### Git 分支列表：一键复制分支名

- 分支行新增复制按钮，点击后按钮变为对勾 1 秒作为确认反馈，复制内容即分支名（`crates/crossh-git-view/src/branch_render.rs`，`f3c66f0`）

### 放着不动也不烧 CPU 了

- 光标闪烁任务以前每个终端标签每 530ms 强制重渲染一次，不管是否聚焦；现在只在光标可见状态真正翻转时才刷新，未聚焦/未开闪烁的标签趋近零开销（`crates/crossh-terminal-view/src/view.rs`，`02b0c60`）
- 状态栏 Git 轮询从每 5 秒 fork 一次 `git status` 子进程放宽到 15 秒，后台 `fetch --all` 仍保持约 5 分钟一次，ahead/behind 徽章行为不变（`src/features/workspace/shell/mod.rs`，`02b0c60`）
- 系统监控面板快照不变时不再每 2 秒强制重绘整个工作区

## 🔧 Chores

- 视图层 crate 化收尾：终端视图抽离为 `crossh-terminal-view`（模型 `crossh-terminal` / 视图 `crossh-terminal-view` 两层分层，对标 Zed 的 terminal/terminal_view），Git/Note 视图抽离为 `crossh-git-view` / `crossh-note-view`，`crossh-git` / `crossh-note` 二进制瘦身为纯装配；删除 `src/shared` 与 `#[path]` 黑魔法，架构检查的禁令推广到整个 `src/bin`（`91e7463`、`1f381bf`）
- 工作区不再直接依赖具体终端视图：新增 `crossh-terminal-view::TerminalItem` trait，工作区经抽象调用状态/标题/焦点/关闭（`9d7dcf1`）
- 2201 行的 `terminal_element.rs` 按位置拆为 layout/paint/input 四个文件，逐字节搬运（`cf2565e`）
- Zed 同步至 `74646bf`（2026-09-17，领先 111 个提交）；附带处理 `unicode-properties =0.1.3` 钉死与 rust-embed 回退 8.11 两处依赖不兼容（`b364f04`）
