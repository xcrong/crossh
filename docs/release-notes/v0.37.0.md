# v0.37.0 — 笔记数据安全修复 + 分屏焦点跟随鼠标

> 2026-10-04 · 基于 v0.36.0 的 5 个提交

## ✨ Highlights

### 笔记不会再丢草稿（重要修复）

- 关窗此前绑在 Escape 上，而未消费的 Escape 会冒泡到窗口级绑定直接关窗，完全绕过脏保护，草稿无声消失（进程是关窗即退出）。现在关窗统一先自动落库，落不了库就拦下并把原因渲染成横幅提示；关窗快捷键改为 ⌘W/Ctrl+W，Escape 只用来退出预览（`crates/crossh-note-view/src/window.rs`，`228c940`）
- 存储层原先对超过 8KB 的内容静默截断：写一半的长笔记被砍掉且无从察觉，"未保存"还会永久亮着。现在超限一律拒绝并提示，上限提到 1MB；落库失败也从只写日志改为渲染给用户看

### Markdown 预览终于是预览了

- 预览此前把 `**`/`*`/`#1 ` 当字面文本渲染，等于直接显示源码符号，粗体/斜体/删除线/标题层级全部失效。改用编辑器已有的 TextView 渲染，删掉 260 行手工事件流代码与 pulldown-cmark 依赖；正文限宽 720px 居中（`crates/crossh-note-view/src/markdown.rs`，`228c940`）

### 分屏支持焦点跟随鼠标

- 开启后鼠标悬停到哪个窗格，焦点（含 accent 边框）就跟到哪个，省去逐个点击。拖选文本与拖拽分隔线期间不切换，避免交互中抢焦点。默认开启，状态栏 crosshair 图标可切换，老配置自动沿用默认值（`src/features/workspace/view.rs`，`78e2a90`）

## 💅 Improvements

- 笔记列表改为虚拟滚动（`uniform_list`），几百条笔记不再每次按键全量重绘；列表宽度可用分隔条拖拽
- 笔记补上行号栏（此前只有代码编辑器有）、笔记内查找面板（⌘F 打开，Enter/Shift+Enter 翻匹配，Esc 关闭）
- 笔记编辑区去掉卡片式边框外壳，呼吸空间改由编辑器 padding 承担，最后一行仍能滚上来、滚动条不压字
- 终端分栏新增快捷键：左右分栏开/关（macOS ⌘D，Win D）、上下分栏开/关（macOS ⇧⌘D，Win ⇧D）、焦点在格间移动（macOS ⌥⌘方向键，Win Ctrl+Alt+方向键），Command Palette 与 tooltip 按平台显示字形（`src/features/workspace/registry.rs`，`1ee2890`）

## 🛠 Fixes

- 顶栏当前 Tab 与侧栏当前行由强调色改为中性选中态，当前项不再靠颜色抢主操作；次要文字提亮至过 4.5:1 对比度，侧栏行高 36→30（`crates/crossh-ui-component/src/tab.rs`，`c4e7b7f`）
- 笔记视图测试此前会打开用户真实笔记库、并往 `~/Library/.../note.db` 里写测试笔记；改为 tempfile 临时库，测试耗时 0.10s → 0.01s
- 软换行后续行的缩进此前硬编码为"取原行前导空白"，与上游新参数语义等价但写死；改为显式传入，换行渲染行为不变

## 📦 升级说明

- 无需手动迁移，直接内置更新即可。
- macOS（arm64/x86_64）、Linux（x86_64/aarch64）、Windows（x86_64）照常发布。
- 行为变更：笔记窗口的 Escape 不再关窗（改用 ⌘W/Ctrl+W）；分屏焦点跟随鼠标默认开启，不想要可在状态栏关掉。
