# v0.39.2 — 修复 Windows 发布打包

> 2026-10-16 · 基于 v0.39.1 的 1 个提交

## 🛠 Fixes

- 修复 Windows 发布打包失败：`f4d935f` 将字体 vendor 进 `crossh-assets` 并移除 Cargo.toml 的 `assets = { git = ... }` 依赖后，`package-windows.ps1` 仍从该行提取 Zed revision，匹配不到导致两个 Windows 构建全部失败、GitHub Release 未生成（`91d9136`）
- `copy-shared-assets.sh` 存在同样问题但被 runner 缓存侥幸掩盖（空 revision 前缀匹配到任意 zed checkout），现已一并改为直接从仓库内 vendor 字体拷贝，不再依赖 Zed checkout
- 打包不再生成无消费方的 `resources/crossh-assets/manifest.json`

## 📦 升级说明

- 无需手动迁移，直接内置更新即可。本版是 0.39 系第一个 Windows 产物（zip + setup.exe）完整的发布，v0.39.1 的 Windows 用户建议升级。
