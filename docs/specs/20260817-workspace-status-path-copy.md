# 工作区状态栏路径复制

## 元数据

- 状态：`superseded`
- 取代者：`docs/specs/20260817-workspace-status-path-copy-toast.md`
- 创建：2026-08-17
- 相关 ADR：`docs/adr/0012-spec-driven-development-loop.md`
- 相关 issue / 路线图项：无
- CI 平台影响：`全部`

## 背景

工作区底部状态栏目前会显示本地终端会话的当前工作目录，但路径只是普通文本，用户无法从这里直接复制。用户需要把当前目录用于命令、文件管理器或外部工具时，只能回到终端或侧栏中寻找其他入口。

## 目标

1. 让用户能够从底部状态栏直接复制当前本地会话的完整工作目录。
2. 让路径区域明确表现为可交互控件，并且不破坏状态栏在最小窗口尺寸下的布局。
3. 保持路径复制与当前活动会话同步，不复制已经切换前的旧路径。

## 非目标

- 不改变远程终端、SFTP 或端口转发视图的状态栏内容。
- 不新增设置项、持久化字段、键盘快捷键或独立的复制按钮。
- 不改变当前路径的来源；复制内容与该本地会话状态栏显示的 `cwd` 使用同一份路径值。
- 不在应用内实现剪贴板历史、复制失败重试或路径格式化规则。

## 行为契约

1. 当活动视图是本地会话时，状态栏应显示该会话当前 `cwd` 的路径区域；路径区域包含文件夹图标和路径文本，并作为一个完整的可点击区域。
2. 当用户用主鼠标按钮点击路径区域时，系统剪贴板应得到该会话当前 `cwd` 的完整文本值；文本使用与状态栏相同的 UTF-8 损失替换规则，不使用截断后的视觉文本。
3. 当用户将鼠标悬停在路径区域时，区域应显示指针光标和状态栏 hover 背景，并提供明确说明可复制路径的 tooltip；hover 不应改变状态栏高度或其他控件的位置。
4. 当用户连续点击路径或快速重复操作时，每次点击都应复制点击发生时活动本地会话的当前 `cwd`，不能因为上一次点击留下旧闭包而复制旧路径。
5. 当本地会话的 `cwd` 变化并触发状态栏重绘后，下一次点击应复制新 `cwd`；当没有活动本地会话时，不应渲染路径复制区域。
6. 当窗口处于声明的最小尺寸或状态栏左侧可用宽度不足时，路径文本可以截断显示，但点击区域仍应保持在状态栏内部可达；tooltip 应能提供完整路径，不得遮挡或挤出状态栏中的切换控件。

## 边界与错误

- 远程活动视图没有本地 `cwd`，因此不显示路径复制区域，也不写入剪贴板。
- 路径包含非 UTF-8 字节时，沿用现有 `to_string_lossy` 文本化行为；不因无法无损表示而 panic。
- 剪贴板写入由 GPUI 平台实现负责；本次变更不引入应用级失败提示，因为该 API 没有返回失败结果。
- 路径变化与点击交错时，以点击回调捕获的当前渲染值为准；重新渲染后创建的新区域必须使用新路径。

## 接口与状态变更

- 无公开 API、设置项、持久化格式或 wire 格式变更。
- 仅增加工作区视图层的剪贴板事件处理和可交互视觉状态，以及对应的本地化 tooltip 文案。

## 平台影响

- macOS、Linux、Windows 的本地工作区状态栏都获得同样的复制行为，剪贴板由各平台的 GPUI 实现承接。
- 本地只验证 macOS arm64 和平台无关逻辑；Linux/Windows 行为由 CI 的 `terminal-compat` job 验证，不在本机交叉编译或运行目标平台检查。

## 涉及纪律

- [ ] Logic must not depend on UI（层级）：复制动作留在已有工作区 GPUI 视图边界，不向纯逻辑 crate 引入 GPUI。
- [ ] Feature-owned settings：无设置变更。
- [ ] 图标纪律：不新增图标资产，沿用现有文件夹图标；不修改 `assets/icons/` 或图标映射。
- [x] 文件规模 < 2000 行：修改范围保持在现有工作区视图与本地化文件内。
- [ ] 工程笔记 / ADR 同步义务：不改变长期架构边界，无需新增 ADR；若实现暴露新的可复用平台问题，再补工程笔记。
- [x] 响应式 UI（最小窗口尺寸可用性）：路径区域允许截断，tooltip 保留完整值，且不挤压状态栏按钮。
