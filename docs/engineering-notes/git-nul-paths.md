# Git NUL 协议路径

## 症状

Git 查看器将包含连续空格或 Tab 的文件名显示为另一条路径，导致 diff、暂存或取消暂存失败；重命名文件的增删行统计可能丢失。

## 根因

`git status --porcelain=v2 -z` 和 `git diff --numstat -z` 都以 NUL 分隔路径。状态记录只有元数据字段使用空格分隔，路径本身不是空白字段；重命名的 numstat 则以空路径、旧路径、新路径三个 NUL 记录编码。对整体记录使用 `split_whitespace()` 或把路径按空格重新拼接都会改变路径。

## 持久规则

解析 porcelain 时只在固定数量的元数据分隔空格处切分，剩余字节整个作为路径。读取 numstat 时必须传 `-z`，并按 NUL 记录处理重命名的旧、新路径。Git 命令失败必须返回可显示错误，不能伪装成空变更列表。

## 验证

在临时 Git 仓库中创建名称包含连续空格和 Tab 的文件，暂存后确认列表中的路径与增删行计数准确。另用非 Git 目录确认状态读取返回错误，而非空列表。

关键词：`Git`、`porcelain v2`、`numstat`、`-z`、`NUL`、文件名空格、重命名
